# Jered Aser Abro – Portfolio

My personal portfolio website, where I present my university and hardware projects in embedded systems, digital technology and machine learning.

🌐 **Live website:** [abrojered.github.io](https://abrojered.github.io/)

[![Screenshot of the portfolio homepage](assets/hero/Portfolio_oberfl%C3%A4che.png)](https://abrojered.github.io/)

## Features

- **Full-screen intro** with a microcontroller background image, darkened on the left so the text stays readable and fading smoothly into the rest of the page
- **Project section** with a description, status and the technologies used for each project
- **Image gallery per project**: only the first picture is shown as a small preview with an "N Bilder" badge; a click opens a large view where you can switch between pictures using the arrow buttons, the ← → keys or a swipe on mobile
- **Skills section** grouped by embedded, programming, hardware and studies
- **Contact section** with email, GitHub and LinkedIn
- **Responsive design** that works on desktop, tablet and smartphone
- **Accessible**: semantic HTML, keyboard navigation with visible focus and respect for reduced-motion settings
- **Custom 404 page** and a microchip favicon in the same design

## Technologies

| Technology | Used for |
| --- | --- |
| HTML5 | Page structure |
| CSS3 (Grid, Flexbox, custom properties) | Layout, design and animations, split into one file per section |
| JavaScript (vanilla) | Image gallery with large view and navigation |
| Google Fonts (IBM Plex Sans) | Typography |
| GitHub Pages | Hosting |

No frameworks, no build step: the site runs directly in the browser.
