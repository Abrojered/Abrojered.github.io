Autonomes Beobachten mit Kameras

Studienarbeit, in Arbeit

Ein Zwei-Kamera-System beobachtet eine Mauer und erkennt Reptilien. Eine feste Kamera überwacht den Gesamtbereich und meldet, ob ein Tier zu sehen ist. Eine schwenk- und zoombare zweite Kamera fährt dann auf das Tier zu und bestimmt die Art. Ein Raspberry Pi steuert das Gesamtsystem. Die Studienarbeit ist so angelegt, dass die Bachelorarbeit darauf aufbauen kann.

Raspberry Pi 5, Raspberry AI Kamera, Raspberry HQ Kamera, IP-Kamera, Objekterkennung

Typing text

Uni Projekt

Typing-Speed-Trainer Eine Desktop-Anwendung in Python zum Trainieren der Tippgeschwindigkeit und -genauigkeit. Der Nutzer bekommt einen Text angezeigt und tippt ihn nach. Jeder Buchstabe wird in Echtzeit geprüft: Richtig getippte Zeichen werden grün, falsche rot markiert. Parallel dazu berechnet die App laufend die Tippgeschwindigkeit, sodass der Nutzer seinen Fortschritt direkt verfolgen kann.
